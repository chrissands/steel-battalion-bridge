Profiles

Profiles are XML files in ~/.config/SBBridge/Profiles, the same format as the Windows version, so you can copy them between PCs.

How it works

Steel Battalion Bridge runs as a background service (systemctl --user status sbbridge). It reads the controller over USB and creates a virtual Xbox 360 controller, which Steam Input and games see like a real one, both in Desktop Mode and Gaming Mode.

An Xbox pad has 15 buttons and 6 axes. The cockpit's flight controls go to the pad, and the rest go to keyboard keys you bind in-game, or to a Shift layer.
